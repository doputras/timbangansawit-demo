# Demo timbangansawit.id

Demo interaktif aplikasi RAM/peron sawit & jembatan timbang **timbangansawit.id**:
aplikasi PC (pos timbang) dan aplikasi HP Owner, berjalan sepenuhnya di browser.

- Data contoh 14 hari terakhir; semua nama, nomor, dan transaksi **fiktif**.
- Perubahan tersimpan di browser masing-masing pengunjung saja.
- Timbangan memakai simulator, cetak berupa pratinjau. Bukan sistem produksi.

Repo ini hanya berisi hasil build statis (tanpa kode sumber).
